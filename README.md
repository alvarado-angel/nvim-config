# nvim-config

my personal nvim configuration

# Requirements

You have to install these technologies:

- python, pip and the virtual environment venv
- build-essential
- golang-go
- the lastest version of nvim.

if you already using linux (a debian distro based) you can use the following script:

```bash
sudo snap install nvim --classic
sudo apt install -y python3 python3-pip python3-venv build-essential golang-go
```
